# LiveCaption Desk · 实时字幕纠错台

LiveCaption Desk 是面向直播字幕校对员的长时间值守工作台。字幕按时间顺序进入待确认区，确认后进入直播区；校对员可以快速处理标点、专有名词、发言人和数字，并在弱网或断线时继续工作。

## 功能

- 实时待确认队列：按时间和序号显示字幕，支持只看需处理内容或异常优先。
- 字幕编辑：修改发言人、正文、标点和数字；支持全角数字、中文数字及常见数字格式规范化。
- 术语快捷替换：规则可限定发言人，可一键应用到当前字幕，并记录使用次数。
- 双边对账（校对台 / 播出机房）：
  - 校对员只持有待确认草稿，机房只持有**已上屏字幕 + 播出时刻**，断网时两边互不可见。
  - 恢复连接后“恢复并对账”：机房已上屏的段落立即**锁定**，本地再新的改动也无法回改，只能生成**追改**排入后面的播出窗口。
  - 机房播出日志没补齐的段落先**挂起**；点“机房补齐日志并重新对账”后再决定投递或转追改。
  - 每档播出窗口容量封顶，正常投递与追改统一按序号排程；装不下的排队顺延到后面窗口，绝不顶掉已上屏槽位。
  - 右栏“播出窗口排程”实时展示每档窗口的锁定槽位、追改槽位和空槽，支持快进演示窗口到期自动上屏。
- 直播确认：使用 `⌘/Ctrl + Enter` 确认后排入播出窗口，已上屏段落同一快捷键登记追改，支持导出 SRT。
- 离线校正：断线后仍可继续修改；恢复后与机房日志对账合并，重复片段和过期内容继续明确提示。
- 异常提示：重复片段、等待超过 90 秒的过期片段、最长等待时间、队列积压、日志挂起和追改顺延都会明确展示。
- 长时使用：提供深色值守界面、14–28px 字幕字号调整和清晰的键盘焦点。
- 键盘操作：`Alt + J/K` 切换片段，`⌘/Ctrl + 1–4` 插入常用标点，`⌘/Ctrl + Z` 撤销，`⇧⌘/Ctrl + Z` 重做。
- 本地持久化：所有修改、术语规则、连接模拟状态、机房日志、窗口排程和界面字号保存在 `localStorage`。

## 技术栈

- Lit 3
- TypeScript 5
- Carbon Web Components 2
- Carbon Styles
- Vite 7

## 开发

```bash
npm install
npm run dev
```

开发服务器默认监听 Vite 的 `5173` 端口。模拟队列每 5 秒自动更新，可用界面中的“模拟断线”和“恢复并对账”演示双边对账流程：首次对账时 seg-4 已上屏旧稿（生成追改），seg-5~7 因机房日志缺失挂起；再点“机房补齐日志并重新对账”，可看到追改在容量封顶的窗口间顺延。

## 构建

```bash
npm run build
npm run preview
```

生产文件输出到 `dist/`。类型检查由构建命令自动执行。

## Docker

```bash
docker build -t sologsb-1011 .
docker run --rm -p 10011:80 sologsb-1011
```

容器内部由 nginx 监听 `80`；宿主端口按根项目端口表映射为 `10011`。
